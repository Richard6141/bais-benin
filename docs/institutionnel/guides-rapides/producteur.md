# BAIS : guide rapide du producteur

Une page pour bien commencer. BAIS est la plateforme agricole du ministère de l'Agriculture, de l'Élevage et de la Pêche.

## Avant tout : se connecter

1. Ouvrez BAIS sur votre téléphone.
2. Saisissez votre NPI (le numéro de votre certificat d'identification) et votre numéro de téléphone.
3. Touchez « Recevoir mon code sur WhatsApp ».
4. Saisissez le code à six chiffres reçu sur WhatsApp.

Votre compte est créé à votre première connexion. Pas de mot de passe à retenir.

Votre exploitation doit d'abord être enregistrée par l'agent de votre commune. S'il ne l'a pas encore fait, l'écran l'indique : il le fera à sa prochaine visite.

## Les 5 gestes essentiels

### 1. Voir mes champs
Touchez « Mes champs ». Vous voyez chaque parcelle, sa superficie et les cultures de la campagne. Un lien ouvre la parcelle sur la carte.

### 2. Lire mes alertes
Touchez « Alertes ». Une alerte vous prévient d'un risque dans votre commune : sécheresse, fortes pluies, chaleur, ravageurs, feux. Elle dit quoi faire.

Si vous avez donné votre accord, l'alerte arrive aussi sur WhatsApp.

### 3. Signaler un problème
Touchez « Signaler ».
1. Choisissez le type de problème.
2. Décrivez ce que vous voyez, en quelques mots.
3. Ajoutez une photo si vous pouvez.
4. Touchez « Envoyer le signalement ».

Sans réseau, le signalement part tout seul au retour du réseau. L'agent de votre commune viendra constater sur place.

### 4. Déclarer ma récolte
Touchez « Déclarer une récolte ». Choisissez la parcelle, puis indiquez la quantité récoltée et, s'il y en a, les pertes. Vos récoltes comptent pour le palmarès des meilleurs producteurs.

### 5. Obtenir mon attestation
Depuis l'accueil, ouvrez « Mon attestation » et touchez « Établir mon attestation ».

L'attestation décrit vos champs et vos récoltes. Elle porte un code QR. Une banque, une assurance ou un programme d'aide la vérifie en scannant ce code.

## Bon à savoir

- **Besoin d'aide de l'État ?** « Solliciter l'État » : conseil, intrants, litige, sinistre. Vous suivez la réponse dans « Mes demandes ».
- **Vos accords.** Dans « Mon compte », vous donnez ou retirez votre accord pour recevoir les messages WhatsApp et pour paraître au palmarès public. Personne d'autre ne peut le faire à votre place.
- **Vos données.** Votre NPI est conservé chiffré. Il n'est jamais affiché.
- **Une question ?** Adressez-vous à l'agent de votre commune.
