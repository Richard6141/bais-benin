# BAIS : guide rapide de l'agent de terrain

Une page pour bien commencer. L'espace agent fonctionne sans réseau : vous travaillez au champ, les données partent au retour du réseau.

## Avant tout : se connecter

1. Ouvrez BAIS sur votre téléphone.
2. Saisissez votre NPI et votre numéro de téléphone.
3. Touchez « Recevoir mon code sur WhatsApp », puis saisissez le code reçu.

Votre compte d'agent est ouvert par l'administration, avec vos communes d'affectation. Si vous vous connectez avant, vous n'aurez qu'un espace producteur : demandez l'ouverture à votre superviseur.

## Les 5 gestes essentiels

### 1. Préparer le hors-ligne
Au bureau, avec du réseau, ouvrez « Préparer le hors-ligne ». Téléchargez vos communes : limites, cultures, campagnes et exploitations connues.

À refaire au début de chaque campagne, ou quand l'écran le demande.

### 2. Enregistrer une exploitation
Touchez « Enregistrer » et suivez les écrans :
1. **Quel producteur ?** Cherchez-le, ou créez-le.
2. **Où se trouve l'exploitation ?** Touchez « Depuis votre position ».
3. **Quelle taille ?** Et les parcelles, avec leur superficie.
4. **Quelles cultures ?** Trois au plus pour la campagne.
5. **Mode de faire-valoir :** propriétaire, locataire ou autre.
6. Relisez avec le producteur, puis touchez « Enregistrer ».

Sans réseau, l'écran dit : « Elle partira dès que le réseau reviendra. » Continuez votre tournée.

### 3. Relever le contour d'un champ
Ouvrez la fiche de l'exploitation, puis la parcelle, puis « Contour de parcelle ».
- Avec du réseau : « Proposer un contour ». Le satellite propose, vous validez ou corrigez.
- Sans réseau, ou pour un petit champ : faites le tour du champ à pied avec le téléphone.

### 4. Vérifier une exploitation
Touchez « À vérifier ». Rendez-vous sur place, puis choisissez le résultat de la visite :
- **Confirmée** : ce qui est déclaré correspond au terrain ;
- **Corrigée** : vous ajustez la superficie constatée ;
- **Rejetée** : exploitation introuvable ou déclaration erronée.

Les parcelles signalées par le satellite arrivent aussi dans cette liste. « À vérifier » demande une visite. Ce n'est jamais une sanction.

### 5. Synchroniser
Dès que vous retrouvez du réseau, ouvrez « Synchronisation ». L'indicateur en haut de l'écran affiche les saisies en attente, envoyées et refusées.

Synchronisez au moins une fois par jour.

## Bon à savoir

- **Alertes de vos communes.** Dans « Alertes », la liste des exploitations concernées indique les producteurs « à prévenir de vive voix » : ceux qui n'ont pas de téléphone ou pas d'accord WhatsApp.
- **Signalements.** Les producteurs signalent un problème ; vous allez constater, puis vous confirmez ou écartez.
- **Vos droits.** Vous ne voyez que les exploitations que vous avez enregistrées.
- **Confidentialité.** Ne montrez pas l'écran d'un producteur à un autre. Ne recopiez jamais un NPI sur papier.
- **Téléphone perdu ?** Depuis un autre appareil, ouvrez « Mon compte », puis « Appareils connectés », et touchez « Déconnecter ». Prévenez aussi votre superviseur.
