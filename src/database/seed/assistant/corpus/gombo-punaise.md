# Gombo : protéger les graines de la punaise du cotonnier

Fiche de démonstration rédigée par l'équipe BAIS à partir de la source citée. Faites confirmer par votre agent agricole avant d'appliquer.

## Le ravageur

Les punaises adultes ont le dos brun et noir avec deux taches noires. Elles laissent des taches noires sur les gousses sèches et abîment les graines.

## Protéger les gousses gardées pour la semence

Attachez un sachet en plastique transparent sur les gousses de gombo. Percez de tout petits trous dans le sachet pour que l'air circule.
- Couvrez les gousses à semence d'un sachet transparent percé de petits trous.
